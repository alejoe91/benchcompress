# WavPack

[WavPack](https://www.wavpack.com/) is a completely open audio compression format providing lossless, high-quality lossy, and a unique hybrid compression mode. It is designed to offer a versatile and efficient solution for audio compression.

## Variants

WavPack supports different levels of lossless compression, which can be adjusted to balance between compression ratio and encoding/decoding speed. The following variants are available:

- **Fast**: Prioritizes speed over compression ratio.
- **Normal**: Balanced between speed and compression ratio.
- **High**: Prioritizes compression ratio over speed.
- **Very High**: Maximum compression ratio with slower speed.
